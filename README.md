# babylife — Siri 음성 육아 기록

"시리야, 육아 기록" → "땡땡이 분유 50미리 5시 15분부터 40분까지 먹었어"
라고 말하면 카테고리, 양, 시작·종료 시간을 해석해서 저장하고, Siri가 결과를 읽어 줍니다.
기록은 웹앱(아이폰 홈 화면에 추가)에서 날짜별로 보고, 고치고, 지울 수 있습니다.

```
아이폰 Siri ─ 단축어 ─▶ POST /api/records {text}
                          │  문장 해석 (api/_lib/parse.js)
                          ▼
                     Neon Postgres  ◀─ 웹앱 (public/index.html)
```

- 서버: Vercel 서버리스 함수 (`api/`)
- DB: Neon Postgres (Vercel Storage에서 무료로 연결, 테이블은 첫 요청 때 자동 생성)
- 문장 해석: 규칙 기반이라 AI 호출 비용이 없습니다. 모든 시각은 한국 시간 기준입니다.

## 말하는 방법

| 말하기 예시 | 저장 결과 |
|---|---|
| 땡땡이 분유 50미리 5시 15분부터 40분까지 먹었어 | 분유 50ml, 17:15~17:40 |
| 분유 백이십 미리 다섯 시 반부터 여섯 시까지 | 분유 120ml, 17:30~18:00 |
| 직수 왼쪽 10분 오른쪽 5분 4시 50분부터 | 직수 양쪽(왼 10, 오 5), 16:50~17:05 |
| 모유저장유 70미리 (또는 유축수유) | 모유저장유 70ml, 지금 |
| 유축 120미리 15분 동안 | 유축 120ml, 15분 전~지금 |
| 낮잠 2시부터 3시 반까지 | 낮잠 14:00~15:30 |
| 밤잠 10시부터 6시 반까지 | 전날 22:00 ~ 오늘 06:30 |
| 기저귀 소변 / 응가 했어 | 기저귀 소변 / 대변 |
| 분유 60 먹었어 10분 전에 | 분유 60ml, 10분 전 |

- **아기 이름**을 말하지 않으면 `BABY_NAMES`의 첫 번째 아기로 기록합니다.
- **오전/오후**를 말하지 않으면 지금 기준으로 가장 최근의 시각으로 봅니다. 저녁 6시에 "9시"라고 하면 오늘 오전 9시, 새벽 1시에 "11시"라고 하면 어젯밤 11시로 봅니다.
- **시각**을 말하지 않으면 지금 시각으로 기록합니다.
- **카테고리 추가**: `api/_lib/parse.js`의 `CATEGORIES`에 한 줄을 추가하면 됩니다.

## 1. 배포하기 (아이폰 Safari로 가능)

1. [vercel.com](https://vercel.com)에 **GitHub 계정으로 가입**합니다.
2. **Add New → Project**에서 `babylife` 저장소를 **Import**하고 **Deploy**를 누릅니다. 프레임워크 설정은 기본값(Other) 그대로 두면 됩니다.
3. 프로젝트의 **Storage** 탭 → **Create Database** → **Neon (Postgres)** → 무료 플랜을 선택하고 이 프로젝트에 **Connect**합니다. `DATABASE_URL`이 자동으로 들어갑니다.
4. **Settings → Environment Variables**에 다음 두 개를 추가합니다.
   - `API_TOKEN`: 길고 임의의 문자열 (예: 비밀번호 생성기로 만든 32자). 이 값이 있어야 기록할 수 있습니다.
   - `BABY_NAMES`: 아기 이름. 여러 명이면 쉼표로 구분합니다 (예: `땡땡이` 또는 `땡땡이,콩이`).
5. **Deployments**에서 최근 배포의 **⋯ → Redeploy**를 눌러 환경 변수를 반영합니다.
6. `https://<프로젝트>.vercel.app`을 열어 `API_TOKEN`을 입력하고, Safari **공유 → 홈 화면에 추가**를 누릅니다.

## 2. Siri 단축어 만들기

단축어 앱 → **＋** → 이름을 **"육아 기록"**으로 정합니다. 이 이름이 Siri를 부르는 말이 됩니다.

1. **입력 요청** 동작을 추가합니다.
   - 질문: `뭐라고 기록할까요?`
   - 입력 유형: 텍스트
2. **URL 콘텐츠 가져오기** 동작을 추가합니다.
   - URL: `https://<프로젝트>.vercel.app/api/records`
   - 방법: `POST`
   - 헤더: `Authorization` = `Bearer <API_TOKEN 값>` (Bearer 뒤에 한 칸 띄우기)
   - 요청 본문: `JSON` → 필드 추가 → 텍스트, 키 `text`, 값은 **제공된 입력** 변수
3. **사전 값 가져오기** 동작을 추가합니다. 키는 `message`, 사전은 **URL의 콘텐츠**로 지정합니다.
4. **결과 표시** 동작을 추가하고 **사전 값**을 넣습니다. Siri로 실행하면 이 문장을 소리 내어 읽어 줍니다.

사용 방법: **"시리야, 육아 기록"** → Siri가 "뭐라고 기록할까요?"라고 물으면 → **"땡땡이 분유 50미리 5시 15분부터 40분까지"**

> 애플 단축어는 Siri를 부르는 말 안에 값을 함께 넣을 수 없어서, 이렇게 두 번에 나눠 말해야 합니다.
> 엄마와 아빠 아이폰에 같은 단축어를 만들면 둘 다 같은 기록에 저장됩니다.
> 시간 해석이 맞는지 미리 보고 싶으면 2번의 JSON에 `dryRun`(부울, 켬)을 추가하세요. 저장하지 않고 결과 문장만 돌려줍니다.

## API

모든 요청에 `Authorization: Bearer <API_TOKEN>` 헤더가 필요합니다.

| 요청 | 설명 |
|---|---|
| `POST /api/records` `{ "text": "..." }` | 문장을 해석해서 저장합니다. 응답 `{ ok, message, record }`. 해석에 실패해도 Siri가 읽을 수 있게 200과 `ok: false`, `message`를 돌려줍니다. |
| `POST /api/records` `{ baby, category, amount, unit, startAt, endAt, memo }` | 필드를 직접 지정해서 저장합니다. |
| `GET /api/records?date=YYYY-MM-DD&baby=이름` | 그날(한국 시간)의 기록을 가져옵니다. |
| `PUT /api/records?id=N` | 수정합니다 (본문은 직접 저장할 때와 같음). |
| `DELETE /api/records?id=N` | 삭제합니다. |
| `GET /api/meta` | 아기 목록과 카테고리 목록을 가져옵니다. |
